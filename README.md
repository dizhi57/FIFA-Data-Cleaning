# FIFA 2022 Players Dataset — Data Cleaning

## Цель проекта
Подготовить датасет FIFA 2022 Players к дальнейшему анализу.

## Что сделано
- проведен обзор структуры датасета;
- проверены дубликаты;
- обработаны пропуски;
- преобразованы даты и числовые признаки;
- рассчитаны дополнительные признаки: возраст, BMI, категории позиций;
- сохранен очищенный датасет.

## Стек
Python, Pandas, NumPy, Jupyter Notebook.

## Результат
Получен очищенный датасет для дальнейшего анализа.

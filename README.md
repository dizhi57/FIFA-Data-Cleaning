# FIFA 2022 Players Dataset — Data Cleaning

## Цель проекта
Подготовить датасет FIFA 2022 Players к дальнейшему анализу: проверить структуру данных, удалить нерелевантные признаки, обработать дубликаты, пропуски и преобразовать признаки.

## Данные
Источник: FIFA 2022 Players Dataset.  
Формат: CSV.

## Что сделано
- проведен первичный обзор структуры датасета;
- исключены нерелевантные признаки;
- проверены полные и частичные дубликаты;
- обработаны пропуски;
- преобразованы даты и числовые признаки;
- рассчитаны дополнительные признаки: возраст, BMI, категории игровых позиций;
- сохранены очищенные данные в CSV/XLSX.

## Файлы
- `data/processed/players_22_clean.csv` — очищенные файл с данными;
- `notebooks/fifa_2022_data_cleaning.ipynb` — Jupyter Notebook с проверкой качества данных и их очисткой

## Стек
Python, Pandas, NumPy, Jupyter Notebook.

## Результат
Получен очищенный датасет, пригодный для дальнейшего анализа.
